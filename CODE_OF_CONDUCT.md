# Community conduct

Be respectful, keep feedback about the work, and welcome contributors with
varying backgrounds and experience. Harassment, discrimination, threats,
doxxing, and publishing another person's private information are unacceptable.

These expectations apply to issues, pull requests, discussions, and other
repository spaces. Maintainers may remove harmful content, close discussions,
or limit participation when needed. Report security concerns through the private
process in SECURITY.md. For other conduct concerns, contact the repository
maintainer through their GitHub profile without posting private details publicly.
